# Mentee SOC Simulation

An AWS lab where mentees investigate simulated cloud activity, locate supporting telemetry, document their analysis, and practice escalation.

## Status

In progress. The first infrastructure goal is to capture AWS management activity in CloudTrail so an analyst can find and explain the evidence.

## Planned components

- Terraform-managed AWS logging and detection infrastructure
- Simulated investigation scenarios
- Analyst runbooks and incident ticket templates
- Read-only analyst access
